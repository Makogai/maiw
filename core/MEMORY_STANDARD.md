# Compact memory standard

- Keep `NOW.md` under 120 lines and `INDEX.md` under 150 lines.
- Prefer links and `path:line` evidence over copied code.
- One fact has one canonical home; other notes link to it.
- Use `topics/architecture.md`, `domain.md`, `conventions.md`, `decisions.md`, and focused subsystem
  notes only when the project needs them.
- Delete obsolete facts instead of accumulating history. Durable decisions stay in `decisions.md`.
- `meta.json.sourceCommit` is the last comprehensively synchronized commit, not merely current HEAD.
- Status is `unlearned`, `partial`, `current`, or `stale`.
